เว็บไซต์ Portfolio / Resume แนะนำตัวเองแบบหน้าเดียว (Single-Page Website) ที่ได้รับการยกเครื่องใหม่หมดตามคำขอ โดยอิงจากข้อมูลจริงจากเว็บไซต์ [jasada-site.vercel.app](https://jasada-site.vercel.app/) ผสานแรงบันดาลใจจากคลิปวิดีโอทั้ง 5 คลิป และใช้ธีมสี **Theme 1 จากคลิป 20 Principles of UX & Animation**

## 🎨 โทนสีและสไตล์ดีไซน์ (Neo-Craft Aesthetic)
- **ธีมสีหลัก (จากคลิปที่ 5 ธีมแรก: Squash & Stretch)**:
  - **Terracotta Tangerine Orange (`#F28044`)**: สีส้มสดใสเป็นจุดโฟกัสหลัก พร้อมไอคอนวงแหวน Concentric Donut Ring
  - **Periwinkle Blue (`#8AAFE6`)**: สีฟ้านุ่มนวลสำหรับสถานะและสายการเรียน
  - **Celadon Sage Green (`#9BB7A5`)**: สีเขียวสดใสสำหรับตราความสำเร็จและสถานะออนไลน์
  - **Jet Black (`#0F172A`)**: ป้าย Tag สไตล์วิศวกรรมโมเดิร์น
- **พื้นหลัง Dot Matrix Grid (ขจัดความแบน + ไม่แล็ก)**:
  - ผืนผ้าใบตารางจุดแบบมินิมอล เคลื่อนไหวลอยเบาๆ ด้วย CSS GPU Hardware Acceleration
  - **ไม่มีวงแหวนหรือสีเบลอตามเมาส์ 100%**: เมาส์เป็นเคอร์เซอร์ปกติของเครื่อง ไม่กินทรัพยากร เลื่อนลื่น 120 FPS!
- **ระบบสลับโหมด Light / Dark Mode**:
  - สามารถกดปุ่มดวงจันทร์/ดวงอาทิตย์ที่เมนูด้านบน เพื่อสลับระหว่างคลีนไวท์มินิมอลกับดาร์กโหมดสุดเท่ได้ทันที

## 🚀 ลูกเล่นอนิเมชั่นจากคลิปทั้ง 5 คลิปที่นำมาประยุกต์ใช้
- **Squash & Stretch (Reel 2159540624770411)**: ปุ่มกดและแท่น Squircle ตอบสนองการกดแบบมีน้ำหนัก ยุบตัวแล้วเด้งคืน
- **Stagger Cascade Entrance (Reel 1861794128508931)**: การ์ดแต่ละใบเลื่อนปรากฏขึ้นมาด้วยจังหวะหน่วงเวลาแบบขั้นบันได 35ms นุ่มนวลตา
- **Tabular Numbers & Concentric Radii (Reel 1661292768785563 & 1115590641265228)**: ตัวเลขสถิติและนาฬิกาเป็นแบบ Tabular ไม่สั่นไหว, มุมโค้งมนของการ์ดด้านในและด้านนอกคำนวณตามหลักเรขาคณิต `inner_radius = outer_radius - padding`
- **Zero Mouse Lag**: ตัดระบบเมาส์เทรลและเรเดียลสปอตไลต์ที่เคยหน่วงออกหมด 100% ทำให้เว็บเบา ลื่นไหลทันที
